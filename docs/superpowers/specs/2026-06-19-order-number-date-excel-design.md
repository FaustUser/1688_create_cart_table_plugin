# Номер и дата заказа в Excel

## Цель

Добавить в Excel-экспорт страницы заказов 1688 номер и дату заказа для каждой товарной позиции.

## Структура Excel

Экспорт заказов содержит колонки:

1. `Номер заказа`
2. `Картинка`
3. `Дата заказа`
4. `Ссылка`
5. `Название на 1688`
6. `Количество`
7. `Цена за ед.`
8. `Доставка по Китаю`
9. `Скидка`
10. `Итого юань`

Картинка привязывается к колонке B. Формула `Итого юань` использует новые координаты колонок: `F*G+H-I`.

Экспорт корзины не изменяется.

## Парсинг

- Метаданные извлекаются один раз из каждого `.order-item-content`.
- Сначала используются известные элементы и атрибуты заголовка заказа.
- Если точные элементы не найдены, выполняется резервный поиск номера и даты по тексту заголовочной части блока.
- Номер заказа сохраняется строкой, чтобы Excel не применял научную нотацию и не терял цифры.
- Дата нормализуется в формат `ДД.ММ.ГГГГ ЧЧ:ММ:СС`.
- Если секунды отсутствуют в исходном значении, записывается `00`.
- Если значение не найдено или не распознано, соответствующая ячейка остается пустой.
- Номер и дата повторяются в каждой строке товара соответствующего заказа.

## Изменения кода

- Добавить чистый модуль для извлечения номера заказа и нормализации даты, доступный в content script и Node.js-тестах.
- Подключить модуль перед `content.js` в `manifest.json`.
- Дополнить `parseOrderBlock()` передачей `orderNumber` и `orderDate` в товарные строки.
- Обновить конфигурацию Excel-экспорта заказов, формулы, ширины колонок и координату drawing с картинками.

## Проверка

- Тесты нормализации китайских форматов даты с секундами и без секунд.
- Тесты извлечения номера и даты из типичных подписей заказа.
- Тест структуры Excel: порядок заголовков, новые координаты ячеек, формула и колонка картинки.
- Проверка синтаксиса всех измененных JavaScript-файлов.
