# Закрепление заголовков Excel

## Цель

Закрепить первую строку с заголовками в XLSX-файлах, создаваемых расширением для страниц заказов и корзины.

## Реализация

- Генерировать стандартный OOXML-блок `sheetViews` с закреплённой областью:
  - `ySplit="1"`
  - `topLeftCell="A2"`
  - `activePane="bottomLeft"`
  - `state="frozen"`
- Вставлять `sheetViews` перед `cols`, сохраняя корректный порядок элементов `worksheet`.
- Не изменять данные, стили, формулы, размеры колонок и размещение картинок.

## Тестирование

Независимый Node-тест проверяет точное содержимое XML закрепления. Синтаксис всех JavaScript-файлов проверяется через `node --check`.
