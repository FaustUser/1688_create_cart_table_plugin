# 1688 → Excel v1.6

## Добавление трек-номеров

- В popup доступны два сценария: сбор нового Excel и обогащение ранее созданного файла.
- Для обогащения выберите XLSX/XLSM с листом `Товары` и столбцом `Номер заказа`.
- Плагин последовательно открывает неактивную страницу доставки каждого заказа, считывает `运单号码` и показывает общий прогресс.
- Несколько трек-номеров записываются в одну ячейку через перенос строки. Если трек ещё не присвоен или страница недоступна, ячейка остаётся пустой.
- Итог скачивается отдельным файлом `*_с_треками.xlsx`; исходный файл не изменяется.
- Popup можно закрыть: состояние хранится фоновым процессом расширения. Кнопка `Остановить` отменяет задание без создания частичного файла.

- Авто-режим на 1688: раскрытие заказов, скролл и сбор Excel из вкладки.
- Импорт базы: загрузите XLSX/XLSM файл (или CSV/TSV) и получите XLSX по шаблону; XLSX также используется как шаблон — данные записываются в лист «Товары» при авто-экспорте.
- Картинки в Excel: изображения скачиваются, webp конвертируется в png и встраивается как drawing (колонка B для заказов, A для корзины).
- Экспорт заказов: номер заказа записывается первым столбцом, а дата заказа после картинки в формате `ДД.ММ.ГГГГ ЧЧ:ММ:СС`.
- Поддержка чисел с запятой: `38394,4` корректно распознаётся как число.
