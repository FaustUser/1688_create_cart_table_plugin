# 1688 → Excel v1.10.2

## Проверка доставки

- В блоке «Проверить доставку» загрузите XLSX/XLSM с заполненным столбцом `Трек номер`.
- Столбец `Статус доставки` создаётся при выгрузке нового файла и при добавлении треков в старый файл.
- Заказы без трек-номеров не открываются. При повторной загрузке файла треки со статусом `Доставлено` пропускаются; если доставлены все треки заказа, страница заказа не открывается.
- В лист «Товары» после столбца `Трек номер` добавляется `Статус доставки`. При нескольких треках в ячейке статусы записываются по строкам в том же порядке.
- Если трек не найден на странице или страницу не удалось проверить, в статусе указывается причина. Ячейки строк без треков остаются пустыми.
- Результат скачивается как отдельный файл `*_со_статусами.xlsx`. Исходный файл не изменяется; задание продолжается при закрытом popup.
- При повторной проверке уже полученные статусы сохраняются. Служебная цепочка вычислений Excel пересоздаётся самим Excel, а определения столбцов остаются упорядоченными после вставки новых колонок.
- Проверка запускает до трёх неактивных вкладок одновременно и читает данные логистики сразу после появления на странице, не дожидаясь окончания загрузки всех ресурсов. На заказ отводится до 45 секунд.
- В блоке «Журнал проверки» видны этапы, ошибки и время открытия страницы, появления данных и полной проверки каждого заказа. Журнал можно скопировать. Все события текущего запуска сохраняются без ограничения числа строк; новый запуск очищает журнал.
- Исходный Excel хранится отдельно от прогресса и читается только при создании итогового файла. После завершения или остановки он удаляется из хранилища расширения.

## Добавление трек-номеров

- В popup доступны два сценария: сбор нового Excel и обогащение ранее созданного файла.
- Для обогащения выберите XLSX/XLSM с листом `Товары` и столбцом `Номер заказа`.
- Плагин проверяет до трёх заказов одновременно в неактивных вкладках, считывает `运单号码` и показывает общий прогресс.
- Компоненты логистики читаются сразу после появления на странице, без ожидания полной загрузки вкладки. При полном наборе треков и привязок к товарам вкладка закрывается после короткой проверки устойчивости данных. Резервное чтение через контент-скрипт запускается только для неполных данных.
- Можно повторно загрузить файл с уже добавленными треками: строки с заполненным `Трек номер` сохраняются и пропускаются. Заказ открывается только при наличии хотя бы одной строки без трека.
- Плагин считывает только номер накладной (`运单号码`) и не записывает внутренний логистический номер (`物流编号`, обычно `LP...`). Ранее созданные строки с таким `LP...` проверяются заново; если вместе с ним уже был настоящий трек, он сохраняется при неудачной повторной проверке.
- Несколько трек-номеров записываются в одну ячейку через перенос строки. Если трек ещё не присвоен или страница недоступна, ячейка остаётся пустой.
- Если заказ разделён на несколько отправлений, трек назначается конкретному товару по ссылке/offer ID и названию, а не всем строкам заказа сразу.
- Служебные поля страницы доставки, включая `发货时间`, в столбец трека не записываются.
- Итог скачивается отдельным файлом `*_с_треками.xlsx` или `*_с_треками_обновлено.xlsx` при повторной загрузке; исходный файл не изменяется.
- Popup можно закрыть: состояние хранится фоновым процессом расширения. Кнопка `Остановить` отменяет задание без создания частичного файла.
- «Журнал поиска треков» показывает результат и время работы по каждому заказу. Все события текущего запуска сохраняются без ограничения числа строк; новый запуск очищает журнал. Журнал можно скопировать.

- Авто-режим на 1688: раскрытие заказов, скролл и сбор Excel из вкладки.
- Импорт базы: загрузите XLSX/XLSM файл (или CSV/TSV) и получите XLSX по шаблону; XLSX также используется как шаблон — данные записываются в лист «Товары» при авто-экспорте.
- Картинки в Excel: изображения скачиваются, webp конвертируется в png и встраивается как drawing (колонка B для заказов, A для корзины).
- Экспорт заказов: номер заказа записывается первым столбцом, а дата заказа после картинки в формате `ДД.ММ.ГГГГ ЧЧ:ММ:СС`.
- Поддержка чисел с запятой: `38394,4` корректно распознаётся как число.
