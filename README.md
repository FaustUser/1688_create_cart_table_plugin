# 1688 → Excel v1.6

- Авто-режим на 1688: раскрытие заказов, скролл и сбор Excel из вкладки.
- Импорт базы: загрузите XLSX/XLSM файл (или CSV/TSV) и получите XLSX по шаблону; XLSX также используется как шаблон — данные записываются в лист «Товары» при авто-экспорте.
- Картинки в Excel: изображения скачиваются, webp конвертируется в png, и встраиваются как drawing (колонка E).
- Поддержка чисел с запятой: `38394,4` корректно распознаётся как число.
